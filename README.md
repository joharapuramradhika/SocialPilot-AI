# SocialPilot-AI
AI-powered social media content generation and publishing workflow


ABOUT
SocialPilot AI is a Python-based web application designed to simplify social media content creation using AI.

FEATURES
1. AI-powered image generation using Gemini.
2. AI-generated captions and hashtags.
3. Content validation.
4. Content approval workflow.
5. Post scheduling.
6. Social media publishing integration.
7. Google Drive integration.

TECHNOLOGIES USED
- Python
- Flask
- Google Gemini API
- HTML
- CSS
- Bootstrap
- Git and GitHub

HOW TO RUN
1. Install Python.
2. Install the required packages using:
   pip install -r requirements.txt
3. Configure the required API keys in a local .env file.
4. Run the application:
   python app.py
5. Open the local URL displayed in the terminal.

NOTE
Content safety filtering may require further improvements. Live publishing and Google Drive integration depend on proper configuration and credentials.
